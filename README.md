## Core Principle

GameForge owns the **semantic world**, not the renderer. This lets graphics improve independently, worlds compile to other engines, and Sophia act as a genuine world-building co-architect.

### Seven Native Systems

| System | Responsibility |
|--------|----------------|
| **ForgeCore** | World state, ECS, events, deterministic simulation |
| **ForgeGeometry** | LOCS topology, LUCA operators, spatial reasoning, procedural terrain |
| **ForgeRender** | Browser graphics, materials, lighting, animation, XR adapters |
| **ForgeMind** | SENTIUM NPCs, behavior trees, goals, memory, agent orchestration |
| **ForgePhysics** | Conventional physics + optional experimental Leakean simulation |
| **ForgeStudio** | Sophia-powered editor, scripting, graph tools, asset and cinematic authoring |
| **ForgeFabric** | Compilation, builds, cloud execution, versioning, collaboration, distribution |

MR7 cartridge architecture: each world declares the cartridges it needs.

## Creation Pipeline

Describe → Sophia Game Planner → Typed WorldSpec → Validation/XTAX → LUCA/LOCS Compiler → Runtime → Render/Play/Simulate → Observe/Decide/Act → Persist + Export.

Operating loop: **Describe → Generate → Inspect → Play → Modify → Save → Export.**

## Alpha Prototype

Open `alpha/index.html` in a browser for the standalone GameForge Studio Alpha 0.1:

- Top-down playable world
- Deterministic prompt parser
- Entity editor, world graph, inspector
- Collectibles, enemies, portal objectives
- JSON import/export
- Local-first, no installation dependencies

This is a real starting point, not yet a 3D Unreal replacement.
